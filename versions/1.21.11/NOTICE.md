# Zenith Client 2.1 for Minecraft 1.21.11

This is a GPL-3.0 modified distribution of Meteor Client, based on its 1.21.11
branch at revision `48030717dc0d4898a195a713fb048bf597fc5b54`:
https://github.com/MeteorDevelopment/meteor-client/tree/48030717dc0d4898a195a713fb048bf597fc5b54

Zenith contributors adapted the source names to official mappings and ported the
Zenith themes, main menu, HUD, procedural effects, sky controls, visual modules
and performance changes to the 1.21.11 game APIs and renderer. Upstream copyright
headers are retained. No Minecraft game binaries or complete mappings are shipped.

Catppuccin and permitted Nora Tweaks source are built in. Their source revisions,
licenses, modifications and Cubiomes corresponding source are in `third-party/`.
Glazed remains separately installed and is excluded from these distributions.
